# Voidspark Conversational WoW Lore Update 0.2.0

This one-click update is for friends who already installed the TrinityCore 12.0.7 Voidspark Playerbot V2 Easy Pack.

1. Stop the server using `Stop-Playerbot-V2.cmd`.
2. Extract the complete update ZIP.
3. Double-click `Install-Lore-Update.cmd`.
4. Enter the existing server folder, such as `C:\repack-12.0.7`.
5. Start the server normally and wait until it reports that it is ready.

No configuration or database editing is required. The updater verifies its files, backs up the current world server, installs the matched executable and migration, and preserves all existing settings.

Test it in game:

```text
/say Who is Arthas?
/say Tell me about the Titans
```

Whisper a bot for longer answers. Afterward, try `tell me more` or `what happened next`.

This update only supports the TrinityCore 12.0.7 Voidspark build. Do not use it with TrinityCore 12.1.x, AzerothCore, or a different expansion.
